# 平台说明与备份建议

本批准备 macOS Apple Silicon 的发布候选安装包。Windows x64 暂缓，尚未提供本版安装产物或实机验收结论。

---

## 1. macOS 安装说明

- 下载 `Huoye-0.1.0-mac-arm64.dmg`（或 `.zip`），将 `活页Huoye.app` 拖入「应用程序」目录。
- **首次打开遇到“已损坏”或“无法验证开发者”提示**：
  由于首版作为个人开源项目暂未购买 Apple 开发者公证证书，应用仅有 ad-hoc 签名，未经过 Developer ID 签名和公证。确认下载来源可信、校验和一致后，可在「终端」移除该应用的隔离属性后重新打开：
  ```bash
  xattr -dr com.apple.quarantine "/Applications/活页Huoye.app"
  ```
- **音视频处理依赖（FFmpeg）**：
  macOS 安装包未内置 FFmpeg 二进制。如果你需要处理视频封面提取、转码或音频格式转换，建议通过 Homebrew 在本机安装 FFmpeg（安装后在系统路径即可被识别）：
  ```bash
  brew install ffmpeg
  ```

---

## 2. Windows（暂缓）

本批不提供 Windows 下载件。源码仍保留 x64 构建入口；恢复 Windows 发行前，需要在 Windows 上安装依赖、构建、实装及卸载验收，并完成随包 FFmpeg 的许可和对应源码交付。当前不能把 macOS 测试结果当作 Windows 已验证。

---

## 3. 数据备份与迁移建议（非常重要）

活页采用**仓库与文件空间分离**的存储架构，备份前先记住这两者的分工：
- **仓库目录**：保存 `library.db`（素材身份、标签、笔记、字段、视图等原始记录）与 `derived.db`（可重建的缩略图和派生索引）。
- **文件空间目录**：保存真正的磁盘原件与历史版本。默认建库时「独享空间」就在仓库关联位置，但如果你关联了**独立的共享文件空间**，它可能在硬盘的其他路径。

### 正确备份姿势
1. **先完全关闭活页应用**（避免 SQLite WAL 写入中途拷贝出不完整快照）。
2. **同时备份仓库目录与它关联的全部文件空间**——只复制仓库数据库不能替代原件；多个仓库共享同一个空间时，该空间只需备份一份，但要保证和各库引用配套。
3. **本机配置不用跟仓库混在一起分享**：工作台分屏布局、已安装插件缓存、MCP 令牌与模型 API 密钥保存在本机应用数据目录，既不属于仓库素材，也不建议随便发给他人。
4. **不要让两个不同版本的应用同时打开并写入同一个仓库**。

## 4. 遇到问题怎么反馈？

非常欢迎到 GitHub Issues 反馈 Bug 或体验建议！提交时带上这些信息能帮我们最快复现：
- 活页版本号、操作系统及芯片架构（如 `macOS 15 arm64` / `Windows 11 x64`）；
- 启用了哪些插件或起始方案；
- 简明复现步骤、预期结果与实际表现；
- 如有截图或日志，**请先检查并遮盖私密资料和 MCP 访问令牌**，不需要上传整个个人仓库。
