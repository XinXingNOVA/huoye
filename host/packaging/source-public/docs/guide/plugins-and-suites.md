# 像活页一样组装：插件、套件与一软多库玩法

活页最核心的乐趣，是**同一份桌面应用，在不同仓库里可以按需组装成完全不同的工具形态**。而且「安装到本机」和「在某个仓库启用」是分开的：装进本机的插件不会强行塞满你的每一个仓库。

从 **v0.2.0** 起，全部随附插件、可选插件和两套起始套件均已内置中英双语词典，随界面语言即时热切换；套件还可附带推荐外观主题，建库时一次采纳。

---

## 一、主程序已内置什么？

下载安装活页主程序后，已经内置了两套开箱起始方案（共附带 12 个可自由启停与卸载的双语插件）：

- **视觉素材库方案**：标签基础（`tags`）、标签分组（`tag-groups`）、文件夹（`collection`）、评分（`rating`）、画幅与尺寸（`image-filter`）、色彩与色板（`palette`）、笔记（`note`）、来源（`source`）。
- **通用资料与表格库方案**：标签基础、笔记、来源、摘录批注（`annotate`）、自定义字段（`fields`）、表格（`table`）、文件编辑（`file-editing`），并支持套件推荐外观。
- **空白底座**：仅保留宿主自带的文件、视图、预览、图片、音频、视频、PDF、文字等基础能力。

## 二、安装 7 个官方可选插件（免编译直装）

下载 [Huoye-0.2.0-plugins.zip](https://github.com/XinXingNOVA/huoye/releases/download/v0.2.0/Huoye-0.2.0-plugins.zip)。解压后即可选择下列 `.hyplugin` 文件安装。

| 插件 | 文件名 | 它给活页带来什么新形态 | 依赖 |
| --- | --- | --- | --- |
| **EPUB 阅读器** | `epub.hyplugin` | 电子书阅读、章节目录、正文搜索、书签与阅读进度接续，跟随主题排版与公共图标（保留手动字号偏好），无缝复用笔记、标签与摘录 | 文件 + 预览（内置） |
| **音乐播放器** | `music.hyplugin` | 本地曲库与音乐播放界面、播放记录管理 | 文件 + 音频（内置） |
| **层级标签** | `tag-tree.hyplugin` | 父子层级标签树与按分支穿透筛选，与标签分组互不冲突 | `tags` |
| **画廊** | `gallery.hyplugin` | 沉浸式画廊浏览布局，支持连续翻阅 | 无 |
| **时间线** | `timeline.hyplugin` | 按收录时间分组浏览素材，支持折叠与快速跳转 | 无 |
| **状态** | `status.hyplugin` | 为素材标记「待处理 / 进行中 / 已完成 / 搁置」状态并在卡片展示 | 无 |
| **看板** | `kanban.hyplugin` | 按状态分列拖拽的看板浏览布局 | 建议搭配 `status` |

### 安装步骤（支持一次多选）
1. 解压 [Huoye-0.2.0-plugins.zip](https://github.com/XinXingNOVA/huoye/releases/download/v0.2.0/Huoye-0.2.0-plugins.zip) 到任意文件夹。
2. 在活页中打开 **「设置 → 套件与插件包」**，点击 **「安装套件或插件包…」**。
3. 一次框选你想装的多个 `.hyplugin`（也可以安装 `.hysuite` 套件文件），核对预览中的名称、版本和依赖校验后确认安装。
4. 打开目标仓库，进入 **「设置 → 功能与方案 → 启停功能」**，勾选刚装好的插件及必需依赖，点击 **「应用并重新加载」** 即可生效。

> **安全提醒**：`.hytheme` 主题包为纯声明式零执行权限，但当前 `.hyplugin` / `.hysuite` 属于可信本地插件体系，没有恶意代码安全沙箱，请只安装官方发布或你信任来源的插件包。

## 三、一软多库：几个推荐的组合玩法

因为插件、外观主题和文件空间都可以**按仓库独立搭配**，你可以把不同用途的资料分建不同仓库，甚至让多个仓库共享同一个托管空间或原地文件夹：

- **灵感与设计图库**：从本地老照片目录起步 + 「视觉素材库」方案 + 深色画廊主题，按需加装 `gallery`（画廊）或 `timeline`（时间线）。
- **个人电子书架与书房**：从「通用资料与表格库」起步，安装 `epub`（EPUB 阅读器）和 `tag-tree`（层级标签），配上「青瓷书房」或昼夜「窗边书房」主题，用 PDF / EPUB 读原书，右侧随手做摘录批注和笔记。
- **项目资料与任务板**：启用 `fields`（自定义字段）+ `table`（表格）+ `status`（状态）+ `kanban`（看板）+「紧凑资料台」主题，同一组资料既能用表格批量改字段，又能切到看板拖进度。
- **本地音乐收藏室**：零复制关联本地音乐文件夹，启用 `music`（音乐播放器）+ `tags` + `rating`（评分），配一张封面壁纸与毛玻璃，即刻变成清爽的本地播放器。

你还可以在 **「功能与方案」** 中把常用的插件启停清单存为**插件组合预设**，以后新建或切换仓库时一键复用。

## 四、停用、更新与数据清理（放心折腾不丢数据）

- **停用或卸载 ≠ 删数据**：在活页里，数据永远属于你的仓库。哪怕停用甚至卸载了某个插件，你写过的标签、评分、自定义字段或笔记依然保存在库里（未知数据块还能通过定义快照基本查看）；重新装回插件后一切原地复活。
- **无痛升级插件**：有新版插件包时，在已安装包旁点击 **「更新…」**，活页会同步更新本机各已登记仓库的绑定并保留启停状态。
- **想彻底清理某插件的残留数据？**：进入 **「设置 → 数据与维护」**，停用对应插件后即可预览影响范围，显式确认清理它的仓库数据或本机界面偏好；不会误伤你的原件和共享记录。
