# 快速入门

首次试用建议用新仓库和几份可丢弃的文件。源码运行见[开发与验证](../development/开发与验证.md)；收到安装包时按该版本的平台说明启动。

## 收集与整理

1. 启动后选择“新建仓库”，填写名称和位置。默认随仓库建立独享文件空间；首次无需配置共享空间。
2. 拖入文件或使用添加入口。文件先存入空间，再按仓库收录规则成为素材。带条件视图可能提示不匹配项，按提示选择收录或跳过。
3. 双击素材打开，空格使用预览。支持的文件类型取决于已启用模块与插件。
4. 安装并启用标签、笔记等插件后，在详情里补充信息。搜索和筛选可组合；把常用条件保存为视图。

源码宿主的普通构建不附带外部包。看不到某功能时，先核对“设置 → 应用”的已安装包，再到“当前仓库 → 功能与插件”勾选并统一应用。停用插件会撤下界面，保留已有数据。

## 浏览与工作台

在素材视图的“显示”中切换浏览布局；表格、画廊、时间线等需要对应插件。它们使用同一查询结果，不复制素材。通过标签页的分屏和“在另一组打开”并排阅读；布局预设可以保存本机工作台安排。插件组合预设单独管理启停选择。

## 撤销与文件处理

仓库数据操作可按历史顺序撤销和重做。基础历史入口在宿主界面，安装“操作历史”后也可从侧栏查看。本次会话默认保留最近 1000 笔、约 64 MiB 载荷预算，最新一笔完整保留；旧会话历史不作为永久审计。

在仓库中移入回收站只处理素材记录，不等于删除原件。文件空间页面负责空间文件、版本和原件处置；系统废纸篓操作会明确说明。永久清理前仔细核对目标层次。

从应用发起编辑会创建或复用工作副本。外部编辑器保存后回到应用完成编辑，确认发布与接纳；不要直接修改受管版本文件。当前文件编辑管理界面由“文件编辑”插件提供。

## 插件与 AI

插件包从应用设置安装、按仓库启用；可停用与卸载，数据仍保留。只安装信任的代码。开发目录用于开发调试，正常试用无需配置。

MCP 在应用设置中按仓库授权。使用界面生成的连接配置，不复制他人的 token；先用只读模式检查，整理写入需明确开启。AI 对话插件的供应商地址、模型和 API Key 由本人填写，独立于 MCP 授权。

## 备份与反馈

关闭应用后备份仓库及所有关联文件空间；共享空间只需保留一份，但必须与各库的引用相配。只复制仓库数据库不能代替原件备份。本机工作台、应用设置和密钥不等于仓库数据，也不要随便分享。

反馈提供版本、系统、复现步骤及实际结果，截图先检查隐私；无需上传整个个人仓库。Windows 使用边界见[Windows 试用说明](Windows试用说明.md)。
