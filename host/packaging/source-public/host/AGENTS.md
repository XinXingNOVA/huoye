# 贡献与维护边界

先读 README.md 和 docs/architecture/设计理念.md；文档索引在 docs/README.md，当前行为以代码和实际运行核对。讨论中的候选能力不视为已实现。

宿主负责框架、公共 API、插件运行环境和应用级 MCP。外部业务插件在独立工程，源码、依赖、测试和产物归插件；只使用公开 API，不读取宿主私有模块或数据库。

保护稳定身份、原件、用户编辑和引用。仓库数据与文件空间分层；UI 和 MCP 复用业务协议。停用插件保留数据，派生计算不能覆盖用户编辑。临时交互状态留在使用场景。

按独立行为和失败风险选择测试，不以数量衡量质量。加工、导入及原生依赖变更需要在真实 Electron 导入新文件；使用临时仓库和独立 RM_USER_DATA。性能优化提供同口径对照。多方协作使用独立工作树，提交仅含本任务范围。

变更同步更新当前文档。长期原则写入设计文档，具体过程留 Git 历史；不把临时路径、凭据和个人配置提交源码。正式分发的插件内容变化需要升版。
