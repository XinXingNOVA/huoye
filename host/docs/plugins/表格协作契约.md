# 表格与自定义字段的 UI 协作

2026-11-10。`table`、`fields` 1.2.0 是自定义 UI 扩展点的首个真实业务接入，复用 [extensions 公共机制](插件自定义UI扩展点.md)。表格负责契约、匹配和显示，自定义字段提供结构编辑，宿主只提供通用目录及错误边界。

## 当前分工

| 层 | 职责 |
| --- | --- |
| table 工程 `contract/` | 公开纯类型 `@resource-manager/table-contract`：列、菜单／表头 props、整组字段工具 |
| table 工程 `tools-contract.ts` | 声明 `table.tools` v1，同步校验、匹配、标题回退；表格界面包裹贡献组件和动作 |
| fields 工程 `table.tsx`、`ui.tsx` | 实现字段菜单、增列、枚举选项，通过 `fields.template` 贡献；核心写命令保持 |
| 宿主 `UiExtensions` | 版本与依赖、稳定排序、只读目录、来源诊断及错误边界 |

`table.tools` 的贡献载荷包含 `match(kind)`，可选的 `columnMenu / header / addOption`。按贡献 `order` 升序、ID 稳定排序，首个匹配生效；休眠定义不提供编辑工具。标题和匹配异常有贡献来源，组件错误只替换该组件，新增选项失败会显示错误，并停止后续单元格赋值；贡献自身已执行的业务写入仍由其事务负责。贡献组件内部的事件与事务仍由该插件负责，不能把 React 边界当作 Promise 捕获器。

类型源码属于表格工程。字段工程把公开的类型归档作为 `file:vendor/*.tgz` 开发依赖携带，安装不要求两个源码目录相邻。归档不包含表格实现，运行包也没有新增 npm 运行依赖。源码提取支持工程内 `vendor` 归档并检查提交文件与锁文件完整性，拒绝绝对路径、上级目录或缺失归档。

## 已退役的旧入口

2026-11-10：核对当前应用最近使用的仓库绑定与已安装 UI 包，并完成新版编辑、停用恢复和进程重开验收后，移除了 `UiPlugin.tableTools`、`UiHost.tableTools`、`ui/table` 类型／SDK 导出、自动补点与声明转换。表格业务的类型和校验均由表格插件维护；宿主只装配 `extensions`，不再维护旧包交叉组合。

table／fields **最低使用 1.2.0，当前建议成对使用 1.3.0**。旧 1.1.x 及更早包不再接续；其他贡献方也需迁到 `table.tools`。此处是代码接口退役，不删除模板、字段值、布局配置、已安装包或仓库选择。其他应用配置目录／未打开的旧仓库仍需自行核对版本。

## 升级与验证

宿主、表格、自定义字段是三个独立提交；已有旧包时，先在带过渡适配的宿主中批量安装并应用两个新版，再更新到移除旧接口的宿主；当前已使用 1.3.0 的仓库无需重复安装。包分别输出在两个插件工程的 `artifacts/table.rmplugin` 与 `artifacts/fields.rmplugin`。沿用布局 ID `table`、模板／字段 ID 和查询配置，无需数据迁移。

构建后 `node tests/electron/sidebar-layout-check.mjs --table-tools` 按 `RM_PLUGIN_SOURCES` 或本机来源清单打包当前工程，运行完整编辑、独立模板编辑、保存选列与重开流程，以及第三方故障探针。入口缺失会失败，不再静默跳过新版验收。旧包覆盖环境变量与交叉升级矩阵随兼容层退役；所有流程使用临时仓库与独立用户目录。

具体测试结果与边界见[开发与验证](../development/开发与验证.md#表格协作契约迁移验证)。第三个插件只需依赖公开类型和 `table.tools`，不需要为自己的字段业务增加宿主分支。


## 独立模板编辑和列配置（1.3.0）

fields 1.3.0 增加独立模板编辑器，表格快捷菜单共用其内部结构编辑控件；不再需要启用表格才能维护字段结构。table 1.3.0 的选列、排序、缺失列保留全部属于自己的 `LayoutDef.Options`，使用现有布局保存接口；`table.tools` v1 的类型和业务协作契约未改变。

模板结构变更作用于该模板及使用者，列配置只作用于当前页面／保存视图的呈现。选列使用稳定的块与字段 ID，跨模板列不会隐式为素材添加模板；明确添加时使用合并写入，保留已有值。两个插件工程 README 提供具体入口和配置说明。本批宿主只更新集成验收与文档，没有修改运行代码、核心、MCP 或公共 API。
