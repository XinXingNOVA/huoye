# 播放记录归属与旧数据接续

2026-11-15。独立 `playback` 插件退役，不再出现在可启用功能或音视频依赖中。播放记录属于理解媒体行为的插件；通用层只复用事件监听与事务记录算法。PDF 的 `pdfreading` 不在本批范围内。

## 当前边界

| 记录／能力 | 责任方 |
| --- | --- |
| `audioPlayback`（位置、完成、次数、时间、最近会话） | 音频 |
| `videoPlayback`（同上） | 视频 |
| 歌曲、歌单、歌词、队列 | 音乐；播放事实通过音频命令共用 `audioPlayback` |
| `usePlaybackRecord` | 绑定媒体事件、10 秒节流、暂停／结束／卸载保存、可选位置恢复；不指定数据块 |
| `playbackCommand` | 事务内验证来源和会话、保存记录；由音频／视频分别注册自己的命令 |

真正播放后才计次，单纯打开不计次；连续使用同一播放器，暂停、恢复和多次保存不重复计次；切换到另一个播放器后再回来播放，会计为新的播放会话。后台较早开始的会话、倒序回调、旧原件指纹及已回收素材不覆盖当前记录。完成时位置归零，保留已完成标记；沿用原先超过 95% 视为完成的口径。记录 `history:false`，不污染用户操作撤销。保存失败不假装成功，通知后在后续播放事件重试；关闭应用瞬间尚未送达的异步写入仍不承诺绝对落盘。

音频／视频停用保留记录；清理派生数据不清播放记录。停用后显式清除该插件全部数据会剥离对应播放记录，保留素材、原文件与另一媒体插件的数据。音乐的歌单／歌词清理不删除音频记录；本机队列仍沿用原有 localStorage，本批不迁移其存储或自动清除。

## 旧库接续（有意保留的兼容边界）

入口为 `core/playback-handoff.ts`，在仓库打开事务、外部包校验之前执行，`playback_handoff_v1` 标记保证不反复搬移。没有旧痕迹的新库不写交接标记。

- 优先用唯一音频／视频信息块判定归属；派生块缺失时用明确扩展名。原值、时间和序号连同字段索引转交新 kind；包括仓库回收站里的记录。
- 同时存在两类媒体、未知扩展名，或目标已存在记录时不猜测、不覆盖；原 `playback` 留作只读休眠数据，在插件数据管理中可显式清理。清理只移除这些未接续旧块，不删除素材身份或已迁入音视频的新块。
- 没有未接续旧记录时，明确 `has: audio` 或 `has: video` 的保存视图，将旧块名替换成对应新名，保留其余条件、排序、展示配置和身份。
- 有未接续旧记录的库，以及跨媒体／无法静态判定的查询保持原样，避免改名后漏掉仍匹配的记录。查询层按旧 `playback` 名称建立只读投影（has、lacks、字段条件、排序和计数），同时读取新记录与残留旧记录；同素材取最近播放记录，不产生重复排序行。它只在查询含旧名称时构建，普通查询继续使用原索引路径。旧工作区筛选、撤销后恢复的旧视图也能继续查询；新功能应直接使用新 kind，不扩展这一兼容层。
- 保留旧定义快照用于历史视图字段说明，不复活独立插件或旧写入口。用户清理旧快照后，旧查询仍能执行，但界面可能按缺失定义显示原字段 ID；建议改用新音频／视频条件后再清理该快照。
- 原先关闭 playback 曾连带关闭音频／视频。交接把这两项实际关闭状态保存下来，不因为删除依赖突然启动加工；之后可分别启用媒体功能。

仓库和文件空间格式不变。交接后不支持回退到不知道新 kind 的旧应用继续写入同一仓库。

## 音乐包更新

音乐 `1.4.0` 依赖 `file + audio`，声明 `media-recording-v1`；同时将已退役 `sidePanels/showPanel` 改为 `toolViews/showView`，才能在当前工作台加载。其持久块定义及已有歌词、歌单、队列格式未改。原包不会被偷偷替换，请安装新 `music.rmplugin` 并在当前库统一应用。未安装音乐的仓库不需要安装它。

公共用法：

```ts
usePlaybackRecord(ref, view.id, source?.seq, {
  position: Number(view.blocks.audioPlayback?.data.position ?? 0),
  save: sample => host.core.run('audio', 'recordPlayback', {
    id: view.id, hash: view.blocks.file.data.hash, ...sample
  }),
  onError: () => host.notify('播放记录保存失败')
}, { restore: false })
```

不要每帧直接 `put`，不要把音乐的本机队列位置当作另一份仓库播放统计。
