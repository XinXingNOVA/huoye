# 视觉素材插件：评分、画幅尺寸与色系

2026-11-15。为第一套视觉素材库方案分批准备能力，现已组合为 [视觉素材库 0.1.1 试用套件](../../suites/visual-library/README.md)，实际发布版本以套件锁定清单为准；下表记录功能首批版本。评分与画幅尺寸首批只改插件；色系批次补充通用独占筛选选项并修复加工器列表输入的比较一致性，未改持久化格式或默认附带清单。

| 插件 | 提供能力 | 数据归属 |
|---|---|---|
| rating 1.0.0 | 单项／批量打星、卡片角标、评分筛选排序、命令面板与 set_rating operation | rating.value，持久属性 |
| image-filter 1.0.0 | 方／横／竖／长图、长边与宽高范围筛选 | image-filter.geometry，可重建；读取 image.width/height |
| palette 1.1.0 | 12 种标准色系、详情色板点击筛选、色值复制 | palette 保留原结构；新增 palette.families 可重建索引 |

独立源码位于插件工作区各自工程，打包产物为各工程 `artifacts/<id>.rmplugin`，使用现有批量安装入口，再按仓库启用。无自动启用和默认布局更改；浏览器采集及整套打包另行推进。色板 1.1.0 需要本批宿主公共能力，先更新并重启宿主。

公共组合链为：插件登记数据块 → 加工或业务命令写值 → 宿主字段索引 → 插件分面调用绑定页面 TabApi.toggleFilter → 普通 Query → 现有保存视图与排序。未为视觉素材写专用宿主筛选或 MCP 分支。

评分用 null 清除，整数 1～5，一次最多 100 项，整体拒绝无效身份、整体撤销；MCP 使用 execute_operation/set_rating 和 requestId。命令面板贡献不等于快捷键绑定，本批不抢占全局数字键。

画幅五类互斥，严格等宽高为方图，长短边 ≥3 为长图；长边阈值明确标像素，不将长边≥3840称作4K分辨率。筛选基于全查询结果，基础视图规则不被临时条件覆盖。支持未评分及跨字段组合。停用／卸载保留数据，清理仅影响各自归属块。

## 验证入口

插件自身：配置工具链后 `npm run configure`、`npm test`、`npm run check`、`npm run pack`。纯逻辑测试归插件工程。

宿主的可选跨插件真实环境验收（先构建宿主）：

```sh
node tests/electron/visual-filters-check.mjs /path/to/rating /path/to/image-filter
```

仅创建临时仓库与独立 RM_USER_DATA；验证新 PNG 在 utilityProcess 加工、组合查询与页面筛选替换、评分详情点击、批量失败拒绝、撤销／重做、operation 回执重放、保存视图、停用保留、画幅清理隔离与重新启用补算，以及独立进程重开后的评分和派生数据。截图与报告输出临时目录。未覆盖 Windows 实机、大库性能或浏览器采集，未直接连接外部 AI 客户端；operation 通过同一核心入口执行。

## 色系批次

色系规则和界面均归 `palette` 插件。普通点击独占切换同字段临时条件；⌘/Ctrl 点击要求同时含多个色系；详情色块点击按所属标准色系切换。保留其他字段条件以及保存视图的基础规则，颜色按字段枚举进入普通 Query，可以保存与重开。右键色块或复制菜单保留复制色值。

任一保留色块命中就算含该色系，同一素材每色系只计一次；采用确定性的 HSV 粗分桶，不是任意色值相似检索或按色差排序。已有色板直接补算色系；停用保留，显式清理涵盖两个派生块，重新启用补算，不影响其他插件。

宿主只补 `exclusive-filter-v1`：`toggleFilter(cond, { exclusive: true })` 原子替换同字段临时条件，避免插件多次调用切换导致条件累积或闭包状态覆盖。旧调用语义不变，参见[公共 UI API](公共UI%20API.md)。组合验证同时发现调度器 SQL 与 JS 对列表/布尔字段加工键的表示不一致，会反复加工、阻塞后续任务；本批统一表示并增加针对性回归。

三插件联合验收：

```sh
node tests/electron/visual-filters-check.mjs /path/to/rating /path/to/image-filter /path/to/palette
```

在上述首批验收基础上，增加新纯红、纯蓝、红蓝混色 PNG 的真实提取与归类、色系范围计数、单选/修饰键叠加、详情色板点击、评分与尺寸组合、界面保存视图、新进程恢复、停用保留、清理隔离与重新加工。使用临时仓库与独立用户目录；未覆盖 Windows 实机、大库性能或主观复杂图片色彩评估。
