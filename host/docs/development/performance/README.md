# 5 万与 10 万项发布性能基线

2026-11-19 归档。两个规模都跑过单空间真实文件库的完整日用流程，10 万项另做了启动和清空搜索的重复测量。下面选用每个场景最近一次同口径实测，保留其源码版本和原始样本，供发布后回归比较。

## 两档都测了什么

真实 Electron 窗口在空闲、后台新增 50 张图、全空间刷新三种状态下，分别执行搜索笔记、滚动到屏外素材、等待新缩略图、点击核对详情、清空搜索并校验全库数量。同时记录收录回执、加工完成时间、核心请求排队和各进程工作集。最终一轮从 50,050 和 100,050 项起步，分别读回 50,100 和 100,100 项。[场景与夹具](2026-11-18/大库日用.md) · [最终日用测量](2026-11-18/增量收录与版本核对.md)

| 日用窗口，源码 `715a5e2` | 5 万档 | 10 万档 |
| --- | ---: | ---: |
| 启动到首屏缩略图可见 | 5,005 ms | 7,829 ms |
| 空闲时输入搜索到结果（含防抖） | 333 ms | 456 ms |
| 空闲时滚动到新缩略图 | 383 ms | 733 ms |
| 新缩略图出现后，点击到对应详情 | 34 ms | 34 ms |
| 后台收录 50 张，直到缩略图与色板全部就绪 | 3.09 秒 | 4.93 秒 |
| 全空间刷新回执（同时浏览） | 1.57 秒 | 3.32 秒 |
| 发起刷新到看到选中素材的详情 | 1.23 秒 | 2.50 秒 |
| 刷新后再空闲 30 秒，核心进程工作集 | 583 MiB | 759 MiB |

上表为一次完整日用流程在各阶段的观察值。10 万档另用同库新进程重复测了三次启动，首屏中位数 7.13 秒，范围 7.01–7.14 秒。原始文件中，`cases[].finalDaily` 是上表的窗口记录，`startupComparisons.final` 是启动复测。[原始时间线、内存与版本](2026-11-18/daily-after-incremental-scan.json)

在同两档库里还单独测了核心的首次存量核对、无变化重复扫描、单文件通知、全空间刷新，以及真实发布一张 PNG 新版到出现待接纳记录。无变化扫描两档均约 0.8 ms，单文件新版通知分别为 43.8 和 90.5 ms。核验时还接纳了新版，确认身份一致、待办清零。[核心对照与取样方式](2026-11-18/增量收录与版本核对.md)

## 10 万项清空搜索专项

从 1 万个搜索命中返回 10 万项全库，直到屏内出现命中范围外的素材、可见缩略图全部加载，再等两帧。旧版 `730547b` 与新版 `a442617` 交错运行，共 48 次。下表取每版每格六次的中位数。5 万档只在日用流程中检查了清空后的数量和画面，两种口径分别保留。[逐段耗时与复测命令](2026-11-19/清空搜索.md) · [48 次原始记录](2026-11-19/clear-search.json)

| 清空方式 | 空闲，上版 → 本版 | 刷新后，上版 → 本版 |
| --- | ---: | ---: |
| 键盘删空 | 1.03 → 0.34 秒 | 4.04 → 1.33 秒 |
| 点击清除 | 1.03 → 0.35 秒 | 0.47 → 0.76 秒 |

刷新后点击清除的中位数升高，同组最长等待从 5.84 秒降至 1.42 秒。后续比较这项应同时看中位数和逐次范围。

## 瀑布流卡片毛玻璃

在同一条五屏滚动路线上对照关闭模糊、只模糊工作台和逐卡模糊。两档库各测常规及密集卡片，保留实际画面呈现间隔、未就绪图块和绘制耗时。[滚动对照与复测命令](2026-11-21/卡片毛玻璃.md) · [逐轮基线](2026-11-21/glass-scroll.json)

## 同期其他测量与适用范围

- **10 万项核心合成库**覆盖 19 个场景，含数据生成、全库查询、组合筛选、排序、标签分面、批读数据块、全文检索、重建索引和加工调度。[核心原始计时](2026-11-18/core.tsv)
- **1,000／10,000 项 Electron 单空间和三空间**覆盖启动、搜索与批读、空间扫描与刷新、导入与缩略图、仅回收仓库记录，以及连同原件处置的预览和执行。多空间和组合删除的规模覆盖到 1 万项。[测量条件与操作表](2026-11-18/README.md) · [窗口原始记录](2026-11-18/electron.json)
- **两档大库的历次对照**保留了优化前刷新超时、进程内存变化，以及第一次刷新优化后的同场景数据，便于追溯等待出在哪一步。[初始日用数据](2026-11-18/daily.json) · [空间刷新优化报告](2026-11-18/空间刷新优化.md) · [对应原始数据](2026-11-18/daily-after-space-refresh.json)

大库窗口基线使用 Apple M5、16 GiB、macOS 26.4、本机磁盘、20 个启用插件。存量为有独立哈希的小 PNG，缩略图已生成，系统可使用文件缓存。数据反映素材数量对索引、窗口与后台并行工作的影响。大体积混合媒体、网络盘和长时间运行的性能仍缺少同口径记录。
