## 职责边界

- 拖放和粘贴开始时，宿主锁定接收实例与落点，逐项返回新建、复用、库内引用或失败结果。插件在该时刻把落点换算到画布坐标。粘贴没有落点时用最近指针或视口中心。关闭目标后不可投递到另一页。
- 拖动二十项时，临时位置留在画面，松手后插件用一条宿主命令提交全部修改和预期版本。每次摆放单独保存归一化裁切区域、灰度等状态。用户接纳源文件的新构图后可以重新核对裁切。
- 小窗外壳、置顶、窗口位置和退出入口由宿主管理，偏好保存在本机。画布平移、缩放、排布和分级取图由插件管理。
- 已知块和字段的反查可直接查索引，例如按图片 ID 查摆放的来源字段、按作品 ID 查成员。需要跨插件枚举所有引用时，再根据具体调用者提炼只读接口。

## 第一批验收

2026-11-22，在独立配置的 Electron 应用和临时仓库中安装实际参考板包，通过 stdio MCP 导入新 PNG，在一块板上放置同一张图 120 次。重试返回原有摆放 ID，回收预览影响 121 个身份，回收站只显示板。恢复后 120 个 ID 全部相同。单删可撤销，混入无效摆放的批量移除整笔回滚。随后在宿主核心入口彻底删除板和摆放，原图仍可查询，输入文件字节保持一致。核心回归另覆盖插件停用、已移除摆放的历史，以及转入另一作品后清空旧作品。

## 第二批验收

在独立 Electron 配置中安装参考板包，通过 MCP 导入新 PNG 并在一块板上重复摆放 20 次。主窗口全选并拖动时，所有块的写入序号保持原值。松手后移动整组，用原生菜单撤销一次即可还原。将同一块板的第二个视图移到独立小窗，分别移动不同项后两处修改均保留。小窗拖动整组期间，MCP 修改其中一项，小窗显示冲突并刷新，其余 19 项的序号保持原值。MCP 在拖动期间移除指针抓住的摆放时，小窗仍能结束手势并报告冲突。

选中多个相同来源的摆放，工作台会话分别报告摆放 ID 与检查器的原图 ID。用小窗原生菜单或主窗键盘移除摆放后，来源和板都仍然可用，撤销恢复原摆放 ID。从素材网格空白处右键新建参考板会自动打开新画布，可以搜索并添加库内图片。

## 第三批验收

主窗接收了重复的库内引用、含重复文件的本地拖入、剪贴板 PNG 和经 HTTP 下载的网页图片。网页图片等待返回时将画布滚动 275 像素并切页，摆放仍落在原板松手时的画布坐标，当前页保持选中。另一次在下载期间关闭原页，迟到的图片没有投给其他页。在独立内容小窗中拖入与粘贴，坐标按小窗视口计算。混合粘贴图片、文本和空文件时，图片成功放置，另两项在小窗提示跳过。切换到「仅保存到文件空间」再粘贴新图片，画布说明保存结果，摆放数量保持原值。

板内直接复制、复制后粘贴都会生成新的摆放 ID，沿用原图、相对位置、归一化裁切及灰度。用 0.2.0 参考板包建板并保存摆放，关闭后换装 0.3.0，读回原 ID 和原字段值，再向同一板写入带裁切的新摆放。

## 第四批验收

在 Apple M5、macOS 和独立配置的 Electron 中，通过 MCP 导入 100 张内容各异的合成纹理 JPEG（3840 × 2160），等待全部缩略图就绪，再把它们放在同一板上。查看全板时显示 100 张缩略图，双击其中一张后只绘制视口附近的 1 个摆放并切换原图。放大后拖动按画布坐标提交，一次全板网格排布可以一次撤销。

在 900 × 621 CSS 像素的画板小窗内，每组连续发送 90 次输入，以 `requestAnimationFrame` 统计帧间隔，约每 120 毫秒采样该小窗渲染进程的工作集。下表为最后一次实测，内存列为采样最大值，不含 GPU 和主进程。

| 操作 | 帧间隔中位数 | P95 | 最长帧 | 渲染进程工作集 |
| --- | ---: | ---: | ---: | ---: |
| 中键往返平移 | 16.7 ms | 18.3 ms | 18.7 ms | 319.1 MiB |
| 围绕视口中心放大再缩小 | 16.7 ms | 17.9 ms | 116.7 ms | 332.5 MiB |

另导入一份两页 PDF，在两个内容小窗分别打开 PDF 和参考板，开启置顶与精简。切换到另一应用后，macOS 窗口顺序确认两个小窗都在它上方。验证了通过应用菜单及顶边控件退出精简，重开活页后两个窗口恢复置顶，参考板恢复精简和独立视角。本轮平台为 macOS，物理触控板手势和 Windows 窗口行为尚待实机验证。

## 第五批验收

在临时仓库通过 MCP 导入红、蓝两张图。第一块板放两次红图和一次蓝图，第二块板只放红图，第三块板只放蓝图。读取第一块板的 MCP 预览，解码得到红、蓝两格。把红图的托管工作副本改绿并接纳新版，前两块板的预览变绿，第三块板的封面序号保持原值。用旧凭据请求新版预览会返回 `changed`。只给原图写笔记时，三块板的序号都保持原值。把蓝图摆放从第一块板转到第二块，两边的预览都随之更新。关闭并重开临时仓库，现成的封面继续可用。

同一宿主加载独立的音乐插件并导入两首内嵌不同封面的 MP3。把第二首移到第一首之前，已打开的音乐导航随即加载新的封面。移空歌单后退回图标，随后可正常删除歌单。另在调度回归中暂停已经算好图像的旧任务，在来源再变后放行它，验证其不能覆盖磁盘图像或加工记录。

持续写入业务数据的自动规则、通用结构化草稿会话，待有独立场景再提炼。主窗、小窗和 MCP 共享仓库写入，选择、视口与拖动预览可以按实例保留。
