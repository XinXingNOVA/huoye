# Windows 试用说明

拿到源码套件，请让能操作 Windows 本机终端的 AI 按[Windows 构建指南](../development/Windows-AI构建指南.md)执行。构建出来的安装程序或 ZIP 才是用于启动应用的产物。

## 安装与开始

- `Huoye-<版本>-win-x64-setup.exe`：安装到当前用户目录；也可解压对应 ZIP，运行其中的 `Huoye.exe`。先完整解压，不在压缩软件内直接运行。
- 本轮为未签名试用构建，实际系统提示与安装情况需要在本机确认。遇到来源或校验疑问先核对交付清单，不修改全局系统保护设置。
- 首次先创建测试仓库，导入几份不重要的图片、文字、PDF 或音视频，确认能查看、整理并在重开后保留。模型接口和 MCP 需要自己配置与授权。

首次创建可直接选择视觉素材库、通用资料与表格库或空白底座。两套方案合计附带 12 个可卸载插件，按所选方案在新库启用。独立可选包与具体版本见本版《插件功能清单》。

## 数据与使用

仓库保存素材记录、标签和笔记等数据块，文件空间保存原件及版本。备份需同时保留仓库和关联空间；独立空间不一定在仓库目录内。不要让日常版与试用版同时写入同一仓库。

仓库移入回收站不等于删除原件；文件空间回收、系统废纸篓和记录清理分别处理。试用时先用可丢弃数据熟悉这些入口。停用／卸载插件保留已有数据，卸载应用程序也不代表清除了仓库或空间。

应用级 MCP 从应用设置配置；不要分享访问令牌。AI 对话另需填写本人接口、模型和密钥。插件是可信本地代码，仅安装信任的来源。

## 验收与反馈

构建脚本会自动运行隔离的打包应用验收；安装器、首次手动启动与实际交互仍需本人检查。本版源码的 macOS 验证不能替代 Windows 实机结果。

反馈请带源码版本／提交、Windows 与 Node 版本、操作步骤、预期和实际结果；构建问题附失败阶段日志末尾即可。先检查截图和日志中的隐私，不需要上传完整个人仓库。

项目及自有插件许可证、完整第三方材料尚待确定和整理，不将本轮测试产物标记为正式开源发行。
