# 视觉素材库 · 0.3.4 试用版

把图片、表情包、参考图和音视频放在一起，通过文件夹、标签、评分、画幅和色系找回素材。默认工作台为单区瀑布流、左上导航、左下智能筛选、右侧详情。它是一份静态套件与起始方案，安装后仍可自由调整。

## 使用

1. 使用支持 `ui-locale-v1` 的宿主。套件自带中英界面词典，切换语言后保留素材数据与筛选条件。
2. 新库：在开始页点击“安装套件…”，选择 `visual-library-0.3.4.rmsuite`，确认安装；点击“用此方案新建仓库 →”，填写名称和位置后创建。
3. 已有库：设置 → 应用 → 插件包 → 添加插件…，选择套件并确认；从结果进入“在当前仓库中预览此方案 →”。默认“补充到当前选择”，勾选应用配套工作台安排，确认选择并统一应用。
4. 拖入图片或用导入入口收录，等待缩略图与色系加工；在右侧打标签、评分、写笔记和来源，在左侧组合筛选。需要反复使用的条件保存为视图。
5. 想调整组合，在插件组合预设里另存副本；工作台也可单独保存。套件原版不覆盖用户副本。

“按这套组合切换”会预览停用组合之外的可选功能；初次在已有库使用建议保持默认补充方式。应用布局保留已有页面和业务数据，不强制关闭阅读页；若焦点仍在阅读页，点击“全部”即可看到智能筛选。不同版本已安装时以预演结果为准，可在方案内选版本，不自动替换用户原来选择的版本。

0.3.4 起，新建视觉素材库采用「银盐画册」。在本库外观设置中可另选主题或恢复跟随应用。

0.3.0 起，文件夹使用宿主的 `entity-roles-v1` 容器角色，成员保持普通素材身份。已有库在“功能与方案”中选择并应用组插件 1.6.0 后生效。可以在开始页“AI 托管”中授权此套件已安装的确切版本。

0.2.0 为标签、标签分组、文件夹、评分和笔记补齐 AI 操作影响声明，需要支持 `operation-effects-v1` 的宿主。安装后在「AI 接入 · MCP」展开此套件，一次允许已安装的确切版本用于 AI 建库；这不会自动提高旧仓库权限。

另外启用宿主已有的预览、图片、视频、音频和文字能力；核心文件与视图能力自然保留。本版不含层级标签、表格、自定义字段、批注、浏览器采集或独立 AI 聊天，也不会自动开启 MCP 权限。已有仓库采用补充方式时，原本启用的其他能力仍保留。

色系是确定性的标准色分类，并非任意颜色相似度搜索。颜色与尺寸会在导入后异步加工，刚收录时可能还没有统计。套件不附带示例素材，不创建标签、文件夹和保存视图，不携带插件内部配置、凭据、个人资料或具体页面身份；详情分区和筛选项的内部排序仍沿用现有界面。

## 更新与移除

新版本套件需要提升套件版本；同 ID、同版本但不同内容不能覆盖。方案保留打包时的推荐版本，但按插件 ID 解析使用能力。已有仓库升级后仍先预览插件选择，不能把安装套件视为已经替换了当前使用版本。

可单独更新插件，套件继续识别同 ID 的已安装版本；推荐包缺失时，不再误报插件缺失。多个候选可在方案预览中选择，已有仓库选择优先保留。已登记套件旁的“更新套件…”可装入同 ID 更高版本，先预览组合和布局差异；更新目录不会自动改变当前工作台或用户副本。未完成任务仍固定已确认的包，需要先接续或取消。

移除套件只撤下原版方案；停用和卸载插件默认保留数据。要删除插件数据，使用设置中的显式数据清理。

## 维护与重建

本目录只保存套件定义、锁定源码和构建工具；8 个插件仍是独立工程，没有新增套件运行插件，也不修改宿主默认交付组合。

在宿主根目录运行：

```sh
node suites/visual-library/build.mjs /path/to/plugins
npm run build
node tests/electron/visual-suite-check.mjs
```

插件父目录应包含上表的 8 个工程，先安装其依赖。构建前核对 `sources.json` 中的版本、Git 提交与干净工作区，并按既有发布包的构建目录生成、校验固定的包 SHA-256。构建环境漂移会直接失败，不能把同版本不同内容再次装入套件。当前 `buildCwd` 仅用于接续历史发布物，不承诺换机器或依赖版本后仍能重建相同字节；分发时优先保存并复用已经发布的包。标准插件打包器同时完成类型与边界检查。产物在 `artifacts/suites/visual-library/`：

- `visual-library-0.3.4.rmsuite`：实际安装／分享的单文件。
- `README.md`：本说明。
- `build-record.json`：宿主、插件提交、版本与包 SHA-256，不含本机源码路径。
- `packages/` 和 `suite.json`：重打套件所需的中间发布物；普通用户不必逐个安装。

后续升级先核验各插件，再更新锁定记录和套件版本。产物不进入 Git，清单、构建脚本、使用说明和集成验收进入 Git。相同版本不混入开发中的未提交修改。

验收仅在临时仓库、独立用户目录进行，覆盖真实套件安装、新建及已有仓库应用、新图加工、组合筛选、重复应用和重启。未做 Windows 实机、大库性能及所有媒体格式兼容性验收；此版用于实际试用反馈，不宣称完整复刻 Eagle。
