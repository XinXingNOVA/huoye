# 动态集合示例

这是宿主公共能力的验证样例，不是自带业务插件。整个目录可以拷贝到宿主外，按独立插件工程打包和开发加载。

从宿主执行 `npm run plugin:pack -- examples/collection-surface /tmp/demo-collection.rmplugin`，安装后启用，点击左栏“动态集合示例”。显示前两项素材，提供查询／排序／布局、选择与本机存档；按钮可临时清空范围和切换角标。双击走示例的打开回调。没有业务块、写操作或自建数据库。

`Provider` 按窗口订阅一次仓库；卡片角标只消费共享状态，不逐卡发起查询。`ResourceCollection` 接收动态 ID 范围，窗口输入规则由 `TabType.inputs` 声明。页面搜索、筛选等随工作区保存，临时范围与角标在重启时重算／重置，不把它们误存成仓库视图。

接入说明见宿主 `docs/plugins/公共集合与页面输入.md`。
