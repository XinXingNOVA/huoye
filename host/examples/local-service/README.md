# 本机服务示例

这是最小的外部 service + UI 包，不是 AI 对话插件。没有 core 入口，也不保存仓库业务数据。演示逐段输出、取消、本机配置和加密凭据；可在独立目录打包。

```sh
npm run plugin:pack -- examples/local-service artifacts/plugins/demo-service.rmplugin
```

更新并重启宿主后，在“设置 → 应用 → 插件包”安装，当前仓库勾选并统一应用重载。从命令面板选择“打开服务示例”：输入文本、开始输出，再切回详情或切换标签页，输出继续；停止按钮会取消实际服务。前缀在本机跨库共享；示例凭据只用于验证是否能解密，不发到网络。请使用临时测试值，清理按钮可删除。

`service.ts` 的实例状态在 start 内，流式输出逐段 await emit，Node 定时器和 fetch 使用请求 signal；`ui.tsx` 在挂载期间持有控制器，卸载取消，不因面板隐藏中断。网络分支仅允许本机回归服务器地址，由自动化验证真实 HTTP 流和取消，不是开放网络代理。

完整契约和限制见[外部本机服务](../../docs/plugins/外部本机服务.md)。服务运行于可信主进程，不是沙箱；不在模块顶层启动工作，不直接访问仓库数据库，不向 UI 返回明文凭据。

1.1.0 使用 `toolViews`＋`tool-placement-v1`，保留工具与初始组 ID。已保存的位置优先，窗口服务与界面显隐仍分别管理。
