# 工作台预设公共接口示例

只依赖公共 UI API，演示三个独立贡献：只读预设、预览／管理界面、工具入口。界面读取 `host.workbenchPresets` 的冻结快照，不引用本插件的原版数组，也能展示其他插件的预设；通过服务另存用户副本、应用和返回。

在宿主根目录打包：

```sh
node scripts/plugins/pack.ts examples/workbench-presets artifacts/plugins/demo-presets.rmplugin
```

在临时仓库安装并启用后，从左下「布局 → 管理布局预设…」查看。也可将本目录复制到独立插件工程，通过按仓库开发目录加载。完整类型和规则见[工作台预设 API](../../docs/plugins/工作台预设API.md)。

`演示界面故障` 会主动抛出渲染错误，验证宿主原位回退；已有预设和工作区不受影响。示例的缩略图只描述中央分屏，不是正式产品的完整界面设计。复杂的管理操作可通过「使用基础预设界面…」完成。本例用于契约验证，不加入默认发行组合。

真实集成验证：宿主构建后运行 `node tests/electron/sidebar-layout-check.mjs --preset-api`，自动使用临时仓库和独立用户目录检查打包／安装、预览不改变布局、用户副本、应用／返回、界面失败回退、停用后保留和重启重新启用。

1.1.0 的工具入口使用 `placement.default` 建议初始组合；工具与组 ID 不变。新声明中的侧栏快照采用当前 v4 格式；旧存档的读取和备份由宿主回归单独验证。

1.2.0 增加 `workbench-content-v1` 的「素材与空间对照」：复用全部集合并采用大图呈现，在另一组准备文件空间，左侧放导航与智能筛选。它不创建笔记、不导入文件、不安装其他插件。原三分屏示例仍保留纯布局语义。

新增端到端入口：`node tests/electron/sidebar-layout-check.mjs --preset-contents`。覆盖已有集合与示例草稿保活、呈现切换／返回、搜索保留、重复应用、保存不夹带业务状态及重启采用最新呈现。
