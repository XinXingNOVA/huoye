# 画廊布局

独立的外部 UI 插件：一张大预览配一条缩略图带，连续浏览同一查询结果。与瀑布流、时间线、表格一样，是现有素材视图的显示方式，不另建素材集合。

## 安装与使用

1. 在应用设置的插件管理中添加 `artifacts/gallery.rmplugin`。
2. 在目标仓库勾选「画廊」，统一应用并重载。
3. 在素材视图的「显示 → 浏览布局」选择「画廊」。

点击缩略图浏览并选择素材，Ctrl／Cmd 多选、Shift 连选、右键和拖动沿用宿主。点击预览图也可选中当前项。左右按钮或方向键切换当前浏览项，Home／End 跳到首尾；这些浏览动作不改多选集合。白色轮廓表示正在浏览，勾选标记表示已选择，Esc 可清空选择。

双击缩略图／预览图，或点击「打开」，用宿主的打开方式进入阅读器，保持当前查询顺序。浏览位置与缩略图滚动位置按页面保存，切换布局、筛选、删除及重启时接续；当前项仍在结果中时保留身份，消失后转到相邻位置。

显示设置支持图片完整显示／填满预览区，缩略图放底部／右侧，以及缩略图大小。选项可随保存视图共享，当前浏览位置留在本机页面状态。

## 规则与边界

- 图片通过公共 `file.path`、`file.seq` 和 `host.url` 读取本库接纳的原图，不自行拼接文件空间路径。原图不可用时保留封面及失败提示。
- 其他内容复用公共 `ResourceCover`。因此文字、PDF、音视频、其他插件数据都能留在同一列表里；呈现取决于启用的封面提供者。
- 仅浏览封面不会启动音视频。阅读 PDF、播放音乐、放大拖拽图片等交给「打开」后的专用界面。第一版没有幻灯片自动播放、并排对比或图片编辑。
- 键盘浏览只处理获得焦点的活动画廊；不会从输入框抢键盘。宿主的删除、附加数据等批量命令仍针对已选择集合。
- 不写任何业务数据块。停用／卸载由宿主回退显示，已有素材、保存视图和配置不被插件删除。

## 开发

要求支持 `browsing-layout-v1` 和 `navigation-order-v1` 的宿主，以及 Node.js 24+。只导入公开 `@resource-manager/plugin-api/…`，React 由宿主共享；无额外运行时依赖，无 core／MCP 入口。

```sh
npm ci
export RM_PLUGIN_TOOLCHAIN=/absolute/path/to/host
npm test
npm run check
npm run pack
```

也可在未提交的 `.rm-dev.json` 写 `{ "toolchain": "../../host" }`。`npm run configure` 生成编辑器 SDK 映射；`npm run dev` 监听打包。通过仓库开发目录选择本工程或父目录，勾选后应用即可开发使用。

`model.ts` 负责当前项接续和缩略图虚拟范围；`ui.tsx` 使用 `useEntityState` 订阅当前项与可见缩略图，复用宿主封面、选择、拖动、打开与页面状态。`core.visible` 报告当前项和附近缩略图以触发按需加工。样式以 `rm-gallery` 限定，不影响其他布局。

缩略图按可见范围挂载，不批量加载原图；同一时刻只有当前图片使用原件。很大的单张原图仍有浏览器解码开销，第一版不做分辨率分级或分块缩放。

## 验证方法
`npm test` 覆盖重排保留身份、删除／空结果／无效状态接续、十万项缩略图范围计算及旧配置回退。

真实界面复验使用临时仓库和独立 `RM_USER_DATA`：安装启用包并导入新图片、文字；验证 Cmd 多选后按方向键不会丢选择，Home／End 切到文字仍显示封面；调整缩略图位置／大小，切换布局与正常重启后核对恢复；删除当前项再恢复，确认焦点不会被恢复项抢回；分屏后检查窄栏与焦点隔离。
