# 批注与摘录插件

随应用附带的外部包 `annotate@1.1.0`。新库推荐按需启用；旧库按原启停交接一次。可关闭、卸载和重装，仓库保留原摘录、笔记、标签、引用与历史。

图片区域、视频时间段、文字、PDF 与 EPUB 内容摘录各自拥有身份，以 `anchor` 依附原素材。阅读器通过公共选区通道发布原文和位置；插件提供标记、批注、检查器和导出；媒体模块继续提供阅读／播放、文字失配、视频截帧与 PDF 指纹检查。`preview` 和 `note` 是硬依赖，四种媒体是可选协作；标签可用时仍支持输入 `#标签`。

```sh
npm run pack
```

图片裁剪经公共 `ctx.images.crop`，原生 sharp 由应用维护，包不携带原生模块。比例区域按 EXIF 转正后的像素计算，只输出仓库缓存 JPEG；裁哪张图、区域、缓存键及加工依赖仍由插件决定。纯格式化及 PDF 文字规范化使用公共 `format` / `pdf-text` 入口，不导入宿主或其他插件私有文件。

`schemas.ts` 冻结历史 anchor v1、v2。`compatibleSchemas` 只声明新增字段和枚举值的兼容旧结构；宿主预检现存记录及历史，原值不变才接续，只更新结构版本，不制造一次用户编辑。当前 anchor v3 新增「内容摘录」和版本化 `locator`；旧类型、字段和记录原样保留。`coreFeatures` 显式要求裁图与兼容旧结构能力，旧宿主会拒绝安装，需先更新应用。

图片／文字／时间轴和 PDF 的专用样式归本包；媒体容器及共享列表布局归宿主。新文字、PDF、EPUB 共用选区动作与标记层；旧记录保留兼容显示。不开放任意数据迁移脚本。

契约和复现命令见[本地插件使用与开发第 13 节](../../host/docs/README.md)与[公共后端 API](../../host/docs/README.md)。

支持功能分类、关键词与使用入口；只调整目录信息和说明，持久定义不变。已绑定旧版的仓库不自动切换版本；新元信息需要更新后的宿主。

## 1.1.0：公共选区协作

更新宿主并安装／选择新版后，选字出现「标记摘录」「添加批注」「复制」。批注仍支持 #标签、独立身份、原文回跳、删除撤销。原文失配或阅读器停用时保留原文及批注，回退通用详情。新记录为 `anchor.type=内容摘录`，来源定位交给 text/pdf/epub 的 `contentLocations` 和公共 surface，不向批注插件加入 EPUB DOM 或章节解析代码。

声明 `content-selection-v1`，旧宿主须先更新；已有仓库显式选择 1.1.0 并重载，不自动替换版本。详细职责、旧结构兼容、源码示例与验证见[公共选区通道](../../host/docs/README.md)。

## 独立开发

运行 `npm ci` 安装本工程依赖；设置 `RM_PLUGIN_TOOLCHAIN` 为宿主工程，或在未提交的 `.rm-dev.json` 中指定 `toolchain`。`npm run configure` 生成本机编辑器 SDK 路径；`npm run check` 检查公共 API 边界和类型（也会刷新 SDK 路径），`npm run pack` 输出 `artifacts/annotate.rmplugin`，`npm run dev` 监听源码。应用按仓库选择本目录，勾选后应用并重载。插件 ID／数据不因目录位置改变。

宿主集成验证由宿主可选测试套件负责；本工程不复制宿主私有测试框架。
