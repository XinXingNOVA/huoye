# 评分 1.0.0

可选的外部插件。给素材附加 `rating.value`（1～5 整数星级），不改变素材内容或原文件。未评分是无值，不以 0 星代表。

- 详情的评分分区：点星打分，再点当前星或「清除」取消评分。
- 选中最多 100 项素材：右键「评分…」批量设置，或通过命令面板执行「评为 N 星／清除评分」。不注册全局数字键，避免与编辑、阅读按键冲突。
- 筛选工具：未评分、精确 1～5 星、4 星及以上；普通点击替换同字段临时条件，再点移除，不修改保存视图的基础规则。与标签／格式／画幅等取交集。
- 排序菜单可选评分升降序；卡片只在有评分时显示 `N★`。

## 公共数据与操作

`rating` 为不可重建属性块，不创建独立实体。通用表格可编辑评分字段；定义校验拒绝小数或越界星级。UI、命令面板、MCP 共用 `set` 命令。

MCP 在仓库启用本插件且有写权限后，经 `execute_operation` 调用：

```json
{"operation":"set_rating","requestId":"rate-batch-0001","args":{"ids":["素材ID"],"value":4}}
```

`value: null` 清除。最多 100 项，重复身份去重；先检查全部为未回收素材，再写入，任一无效则整批拒绝。宿主提供整批撤销与 requestId 回执重放。评分是替换操作，不做隐式合并。

筛选使用既有 `eq/range/empty`，排序为 `{kind:"rating",field:"value"}`。停用后评分可读且查询仍可使用快照；显式清理只剥离评分，不删素材、原件或保存视图。

## 开发与交付

通过 `RM_rating_TOOLCHAIN` 或本机 `.rm-dev.json` 的 `toolchain` 指向宿主工程。运行 `npm ci`、`npm run configure`、`npm test`、`npm run check`、`npm run pack`。插件源码、纯逻辑测试和产物归本工程；仅依赖公开插件 API。

在应用「设置 → 应用 → 插件包」安装 `artifacts/rating.rmplugin`，再到当前仓库勾选启用，统一应用并重载。也可将本工程放入仓库开发目录。

不自动安装到日常仓库，不修改其他插件或默认交付方案。停用与卸载默认保留数据；清理必须在数据维护中显式预览确认。

## AI 操作权限

本版声明 `operation-effects-v1`，需要支持该特性的宿主。设置和清除评分属于 `data`，允许 `organize`／`admin`。安装后还须在目标仓库启用新版本；旧包不会因宿主升级自动获得声明。
