# 独立插件维护

本工程负责文件编辑的界面：列表、角标、详情分区、工作副本处理与编辑器选择。只导入公共 `@resource-manager/plugin-api/…`，不得读取宿主私有路径、任务目录或数据库。工作副本和恢复由宿主服务托管；卸载界面不能结束任务。

通过 `RM_PLUGIN_TOOLCHAIN` 或本机 `.rm-dev.json` 指定宿主，执行 `npm run check`、`npm run pack`。当前只有宿主提供的 React peer，没有需另装的运行依赖；新增依赖应归本工程并提交锁文件。插件纯业务测试留在这里，跨宿主的工作副本／原生操作回归保留在宿主。验证用临时仓库和独立用户目录。正式分享改变包内容需升级版本。
