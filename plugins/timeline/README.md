# 时间线布局

独立的外部 UI 插件。对当前视图的查询结果按**收录时间**分组浏览，不创建数据块，不改变原文件、素材身份或筛选规则。

## 安装与使用

1. 在应用设置的插件管理中添加 `artifacts/timeline.rmplugin`。
2. 在目标仓库勾选「时间线」，统一应用并重载。
3. 打开素材视图，在「显示 → 浏览布局」选择「时间线」。

显示设置可以选择按天／月／年分组、时间升降序和卡片大小。点击日期标题折叠；顶部可跳到指定日期。选择、Shift 连选、Ctrl／Cmd 多选、右键、拖动和双击打开沿用宿主。

每个页面分别保存滚动位置和折叠状态。切换布局或重开仓库后恢复；布局选项可随保存视图共享，折叠与位置属于本机页面状态。停用或卸载后，宿主临时回退到瀑布流，素材数据不受影响。

## 规则与边界

- 日期来自仓库身份的 `createdAt`，按本机时区分组，不是文件修改时间／拍摄时间。相同时间保持输入查询的顺序，未知日期排在最后。
- 时间线内部按时间排序；宿主的查询仍决定素材范围，宿主排序只影响同时间项的先后。
- 折叠只改变呈现，不移除素材或清空已有选择。Shift 连选与双击后的阅读器导航按当前展开组的顺序进行；右键打开由宿主的通用导航规则处理。
- `ResourceCard` 提供封面、标题、角标、搜索命中与拖动；卡片固定比例，保留宿主封面的绘制方式。
- 第一版不支持自定义日期字段、按拖放修改日期、横向时间轴。

## 开发

要求支持 `browsing-layout-v1`、`navigation-order-v1` 和 `entity-identities-v1` 的宿主，以及 Node.js 24+。本工程只导入公开 `@resource-manager/plugin-api/…`；无新增运行时依赖，无 core／MCP 入口。

```sh
npm ci
export RM_PLUGIN_TOOLCHAIN=/absolute/path/to/host
npm test
npm run check
npm run pack
```

也可以在未提交的 `.rm-dev.json` 写 `{ "toolchain": "../../host" }`。`npm run configure` 生成编辑器所用 SDK 映射；`npm run dev` 监听打包。宿主的仓库开发目录可直接选择本工程或其父目录，勾选本插件后应用。

`model.ts` 负责分组、日期排序和虚拟行几何；`ui.tsx` 负责数据读取、页面状态和公共事件接入；样式全部以 `rm-timeline` 限定作用域。

时间线分批通过 `host.core.getIdentities` 读取结果的收录时间，每批最多 8192 项。已有时间会在当前布局内复用。日期齐备后才按本机时区分组，并为视口附近的卡片加载内容。

## 验证方法
`npm test` 覆盖本地日期边界、同时间稳定顺序、未知日期、折叠后的定位和虚拟行边界、旧配置回退。

真实界面复验使用临时仓库和独立 `RM_USER_DATA`：安装并启用包，导入新图片和文字，切换布局，折叠／展开，调整分组与顺序，Shift／Cmd 多选、右键选择，从卡片打开阅读器检查前后项，滚动后切换布局及正常重启，对比恢复位置。在窄分屏和另一个布局同时显示时重复。
