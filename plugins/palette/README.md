# 色彩与色板 1.1.0

可选外部插件，依赖 `preview` 的缩略图。提供色板、占比和 12 种标准色系筛选：红、橙、黄、绿、青、蓝、紫、粉、棕、黑、灰、白。

## 使用

- 在筛选工具的「色系」中点击颜色：切换当前色系，再点已选颜色清除；⌘/Ctrl 点击叠加「同时包含」多个色系。
- 在详情「色板」中点击色块：筛选该色块所属的标准色系。右键复制色值，或通过「复制色值…」选择复制。
- 保留搜索、标签、评分和尺寸等其他条件，使用现有「保存为视图…」保存组合。
- 数量按当前集合范围计算，忽略本字段临时条件，保留基础视图与其他筛选条件。按素材去重，多色素材可同时属于多个色系；数量不是叠加该色系后的交集预测。
- 没有可筛选的集合页面时，详情点击会提示先打开集合，不自动创建或跳转页面。

这是按标准色系粗筛：提取出的任一保留色块命中即算包含，不是任意色值的感知相似度排序。既有色板提取会忽略占比小于 2% 的色块；色系归类不另加占比阈值。规则是确定性的 HSV 分桶，低明度归黑、低饱和归灰/白，另区分棕与浅红粉色；具体边界在 `lib/color-families.ts`。不会识别前景对象或排除背景色。

## 数据与升级

- 原 `palette` 数据块（颜色、权重）不改结构，新加可重建 `palette.families.values` 枚举列表索引，内部派生块不进入详情信息栏。
- 新加工器直接读取已有色板补算色系，不要求重新读取原文件；原提取器版本不变，不因本次升级强制重提全部色板。
- 停用／卸载默认保留数据；本插件的数据清理涵盖色板和色系索引，保留素材、原件、代表图、缩略图及其他插件数据。重新启用可以补算。
- 旧 `preview` 色板的一次归属交接仍由宿主负责。

## 开发与安装

使用 `RM_PLUGIN_TOOLCHAIN` 或 `.rm-dev.json` 指定当前宿主，运行 `npm run configure`、`npm test`、`npm run check`、`npm run pack`。产物：`artifacts/palette.rmplugin`。

本版需先更新并重启宿主，再安装/更新插件，按仓库启用并应用。UI 能力要求 `scoped-facets-v1`、`exclusive-filter-v1`、`window-surfaces-v1`；核心需要 `image-sample-v1` 和 `data-lifecycle-v1`。旧宿主会通过能力声明拒绝加载，避免忽略独占筛选选项而错误累加。

颜色提取与归类属于本插件；解码使用宿主受限 RGB 采样接口，无新增原生依赖。单元验证覆盖标准色、边界、去重、非法值与实际提取接续；真实 Electron 跨插件验证由宿主的 `tests/electron/visual-filters-check.mjs` 接收第三参数本工程路径执行。
