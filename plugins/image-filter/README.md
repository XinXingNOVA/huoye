# 画幅与尺寸 1.0.0

可选的外部插件，依赖宿主图片能力 `image`。利用现有图片宽高生成 `image-filter.geometry` 派生块，不重复解码或读取原文件，也不新增缓存文件。启用后调度器处理已有图片，新导入或尺寸改变时重新计算。

## 筛选规则

- 方图：宽 = 高。
- 长横图：宽 / 高 ≥ 3；长竖图：高 / 宽 ≥ 3。
- 横图、竖图：相应方向且不属于上述长图。五类互斥，不把长图再次计入横／竖图。
- 长边：不区分横竖；提供 ≥1080、≥2160、≥3840 像素快捷条件，这些是长边阈值，不称作 1080p 或 4K。
- 宽度、高度、长边可输入最小／最大像素，包含边界；只填一侧表示无另一侧限制，均留空后应用清除该字段临时条件。
- 空、零、非有限或无效图片尺寸不生成画幅块。分类以 `image` 提供的宽高口径为准，不另作方向解释。

画幅计数遵循当前集合范围，剔除自己的临时画幅条件，保留搜索、基础规则与其他字段筛选。点击替换同字段条件，再点取消；所有筛选在仓库查询层执行，不只过滤当前加载的卡片。可与评分、标签、格式组合并保存为视图。

## 数据与生命周期

派生字段为 `shape`（枚举）、`ratio`（宽/高）、`longSide` 和 `shortSide`，均可索引。宽高筛选直接查询 `image.width/height`；通过通用查询构建器还可指定宽高比与短边范围。派生块隐藏通用详情技术字段，不增添信息噪音。

停用默认保留派生数据但不再更新；停用期间新增图片不会有画幅分类，重新启用补算。清理只删除本插件派生数据，不删除 image、原件、缩略图或保存视图。未增加 MCP 写命令；AI 使用通用查询读取和组合这些索引字段。

## 开发与交付

通过 `RM_image-filter_TOOLCHAIN` 或本机 `.rm-dev.json` 的 `toolchain` 指向宿主工程。运行 `npm ci`、`npm run configure`、`npm test`、`npm run check`、`npm run pack`。插件源码、纯逻辑测试和产物归本工程；仅依赖公开插件 API。

在应用「设置 → 应用 → 插件包」安装 `artifacts/image-filter.rmplugin`，再到当前仓库勾选启用，统一应用并重载。也可将本工程放入仓库开发目录。

不自动安装到日常仓库，不修改其他插件或默认交付方案。停用与卸载默认保留数据；清理必须在数据维护中显式预览确认。
