# 像活页一样组装：插件、套件与一软多库玩法

活页最核心的设计，是**同一份桌面应用，在不同仓库里可以按需组装成完全不同的工作台**。而且「安装到本机」和「在某个仓库启用」是分开的：装进本机的插件不会强行塞满你的每一个仓库。

---

## 一、活页的四种标准内页产物

| 产物后缀 | 名称 | 作用 | 安装入口 |
| :--- | :--- | :--- | :--- |
| `.hysuite` | **场景套件** | 一组打包好的插件 + 分屏/侧栏预设 + 推荐主题，适合按场景一键开箱 | 开始页 / 设置 → 套件与插件包 |
| `.hyplugin` | **单装插件** | 扩展单一数据块、浏览视图、文件打开器、工具工坊或算力引擎 | 设置 → 套件与插件包 |
| `.hyruntime` | **共享运行包** | 离线本地模型与原生推理程序，导入一次跨库共享 | 设置 → 计算引擎 → 共享运行包 |
| `.hytheme` | **主题包** | 纯声明式昼夜配色、壁纸构图、阅读排版与 SVG 图标（零执行权限） | 设置 → 外观与主题 |

## 二、主程序自带什么 vs 官方扩展仓提供什么

### 1. 主程序开箱自带（无需额外下载）
- **两套起始方案**（共 12 个基础双语插件）：
  - **视觉素材库**：文件夹（`collection`）、标签基础（`tags`）、标签分组（`tag-groups`）、评分（`rating`）、画幅与尺寸（`image-filter`）、色彩与色板（`palette`）、笔记（`note`）、来源（`source`）；
  - **通用资料与表格库**：标签、笔记、来源、批注（`annotate`）、自定义字段（`fields`）、表格（`table`）、文件编辑（`file-editing`）；
  - **空白底座**：仅保留宿主自带的文件、视图、预览、图片、音频、视频、PDF、文字基础能力。
- **7 个轻量基础可选包**（随主仓 Release 提供）：`epub`、`music`、`tag-tree`、`gallery`、`timeline`、`status`、`kanban`。
- **4 套内置昼夜主题 + 2 套示例主题**：内置活页·标准、银盐画册、青瓷书房、紧凑资料台；主仓 `host/examples/themes/` 随附「蓝晒」与「银杏·秋光」。

### 2. 官方扩展仓库 `huoye-extensions`（按场景进阶）
更多完整垂直工作台统一发布在独立仓库 **[XinXingNOVA/huoye-extensions](https://github.com/XinXingNOVA/huoye-extensions)**，也可以在 **[官网扩展馆](https://huoye.org/catalog)** 按分类筛选与直链下载：

- **8 套场景套件（`.hysuite`）**：画室精审、灵图与灵眸、设计工坊、青瓷书房、黑胶放映与听译、办公与档案工坊、效率魔方、仓库洞察；
- **2 个离线共享运行包（`.hyruntime`）**：Chinese-CLIP 中文语义视觉、Whisper 离线语音听译（详见 [本地离线算力与共享运行包](compute-and-runtimes.md)）；
- **独立主题（`.hytheme`）**：博丽缘侧等精选扩展主题；
- **38 个单装插件（`.hyplugin`）**：按需单装或自由拼装。

## 三、安装步骤与安全边界

1. 在活页中打开 **「设置 → 套件与插件包」**，点击 **「安装套件或插件包…」**（支持一次多选 `.hyplugin` 或选择 `.hysuite`）。
2. 核对预览中的名称、版本与依赖关系后确认安装。
3. 打开目标仓库，进入 **「设置 → 功能与方案 → 启停功能」**，勾选刚装好的插件（或直接应用套件附带的工作台预设），点击 **「应用并重新加载」** 即可生效。

> **安全提醒**：`.hytheme` 为纯声明式零执行权限；`.hyplugin` / `.hysuite` / `.hyruntime` 属于可信本地扩展体系，当前不做恶意代码沙箱，请只安装官方发布或你信任来源的包，并核对 `SHA256SUMS.txt`。

## 四、一软多库：推荐组合思路

因为插件、外观主题、算力引擎和文件空间都可以**按仓库独立搭配**，你可以让不同资料各居其所，甚至多个仓库共享同一目录或托管空间：

- **灵感与画室库**：零复制挂载现有参考图目录 + 「画室精审」套件 + 银盐画册（暗房），参考板可撕成置顶小窗贴在绘图软件旁；
- **个人藏书与精读库**：「青瓷书房」套件 + 青瓷书房主题，统一阅读 EPUB、Kindle、PDF、漫画与 TXT，书摘一键跳回原文；
- **文档与归档库**：「办公与档案工坊」套件 + 紧凑资料台主题，直接检索 Word / PPT / PDF / 压缩包与表格，需要交付时直接导出到本地不入库；
- **播客与拉片库**：「黑胶放映与听译」套件 + Whisper 运行包，看片听音之余按需转出可搜台词的时间码字幕。

你还可以在 **「功能与方案」** 中把顺手的插件组合保存为**插件组合预设**，以后新建仓库一键复用。

## 五、停用、更新与数据清理（放心折腾不丢数据）

- **停用或卸载 ≠ 删数据**：数据永远属于你的仓库。哪怕停用甚至卸载了插件，写下的标签、评分、自定义字段或笔记依然留在 `library.db` 中（未知数据块可通过定义快照基本查看）；重新装回插件后原地恢复。
- **更新插件**：在已安装包旁点击 **「更新…」**，活页会同步更新本机各已登记仓库的绑定并保留启停状态。
- **彻底清理残留数据**：进入 **「设置 → 数据与维护」**，停用对应插件后即可预览影响范围，显式确认清理它的仓库数据或本机界面偏好；不会误伤你的原件与共享记录。
