# 5 分钟上手活页

这份指南带你用几份随手找来的图片、PDF 或文字，快速走完一次「建库（含零复制关联本地文件夹） → 收录 → 整理 → 多形态浏览 → 主题与安全编辑」的完整体验。

> 首次体验建议新建一个测试仓库，放几份不重要的样本文件试试手，熟悉仓库与文件空间的关系后再接入主力资料。

---

## 1. 创建你的第一个仓库（两种起步方式）

打开 **活页（Huoye）**，在开始页根据你的资料现状二选一：

- **方式 A：新建仓库（托管副本，带完整历史版本）**
  - 点击 **「新建仓库」**，填好名称与保存位置；文件空间保持默认的「随仓库新建独享空间」即可。
- **方式 B：从本地文件夹开始…（零复制直连已有目录）**
  - 如果你的照片、电子书或论文已经整理在电脑的某个文件夹里，点击 **「从本地文件夹开始…」** 选择该目录，再把活页仓库保存在来源目录以外的位置；
  - 首次打开仓库时，可直接按文件类型（图片、文档或自定义后缀）预览数量并一键收录。**原件留在原处，不复制、也不往你的文件夹里写入任何隐藏文件。**

> 如果你之前已经建过活页仓库，点击 **「打开已有仓库」** 即可直接打开；如果不小心选了一个普通非空文件夹，开始页也会直接引导你转成原地关联建库。

在起始方案里，内置了三种开箱选择（全部支持中英双语）：
- **视觉素材库（推荐初次体验）**：预装文件夹、标签基础与分组、评分、画幅尺寸、色彩与色板、笔记、来源，打开就是单区瀑布流 + 左上导航 + 左下智能筛选 + 右侧详情。
- **通用资料与表格库**：预装标签、笔记、来源、摘录批注、自定义字段、表格视图与受控文件编辑，适合整理 PDF、文章、结构化清单。
- **空白底座**：只启用宿主基础能力，适合想自己从零挑选插件的用户。

---

## 2. 拖入素材或按类型收录，等待后台加工

- **导入托管文件**：把图片、PDF 或纯文本直接拖进主窗口，或点击最左侧快捷栏的 **「导入文件」** / **「新建文字」**。文件会先进入受管文件空间获得稳定身份与版本保护，再收录进当前仓库。
- **关联更多本地文件夹**：在仓库内随时可通过开始页或 **「文件空间」** 关联额外的原地目录，按后缀预览并批量收录。
- **后台加工**：活页会在后台自动生成缩略图；启用「画幅与尺寸」和「色彩与色板」后也会自动算出宽高比例、色板与标准色系。
- **条件视图拖入预检**：如果在带筛选条件的视图里拖入外部文件，未满足条件的条目会先弹出预检提示，由你决定跳过还是仍收录进库。

---

## 3. 整理、组合筛选与保存视图

选中任意素材（支持多选批量操作）：
- **右侧详情栏**：打标签、评 1～5 星、写笔记、记来源；启用自定义字段后可挂载模板并填写结构化字段。
- **左侧智能筛选**：点击标签、星级、画幅或色系即可实时叠加筛选。侧栏计数随当前页面查询范围联动，但不会因为选中某个标签就藏起同组兄弟标签。
- **保存为视图**：把常用的筛选与排序（例如“4 星以上横图”或“某项目待阅 PDF”）保存为视图。同一份素材可同时出现在多个视图中，不复制文件。
- **双击 / 空格**：空格快速预览，双击打开阅读或查看；安装了多种打开器时可在右键菜单选择「打开方式」并记住按扩展名的默认偏好。

---

## 4. 切换形态、自由分屏与独立小窗

同一份查询结果，可以随时切换成不同的呈现方式：

- **切换浏览布局**：在集合页顶部打开 **「显示」** 菜单，即可在内置瀑布流与已启用的布局插件（表格、画廊、时间线、看板等）之间切换；布局选项可随视图保存。
- **自由分屏与独立小窗**：
  - 把标签页拖到中央区域四边即可递归分屏，一边翻列表一边对照阅读或编辑；
  - 右键标签页或拖出主窗口，可拆成独立的**内容小窗**（共享同一仓库会话、草稿与本库外观主题）；
  - 按 `Cmd + P`（Windows 为 `Ctrl + P`）随时呼出命令面板。
- **保存工作台预设**：把顺手的分屏与侧栏安排存成命名预设，按任务一键切换。

## 5. 撤销、安全编辑与原件管理

活页把“修改仓库元数据”和“动磁盘原件”分得很清楚：

- **会话撤销 / 重做**：打标、写笔记、评分、改字段等常规操作均支持线性撤销与重做（默认保留最近 1000 笔），可在操作历史面板查看明细。
- **编辑原地收录的文件**：右键选择 **「在外部应用中打开原件」**。保存后回到活页，双击素材，或在详情里点 **「核对并预览新版…」**。核对本库记录的大小、内容摘要和来源的当前内容后，点 **「接纳新版」**。标签和笔记保留。外部覆盖可能使旧正文无法取回。需要保留历史原件时，请先 **「转为托管副本…」**，再编辑托管文件。
- **编辑托管文件**：右键选择 **「编辑文件」**，活页会准备一份**受控工作副本**；外部保存后回到活页点 **「完成编辑」**，确认后即发布为文件空间的新版本并由本库接纳。
- **回收与缺失核对**：
  - 在仓库里把素材「移入回收站」只影响本库记录，**绝不删除磁盘原件**；
  - 原地目录改名或移动文件后会自动接续身份；若外部确实删了原件，可在 **「文件空间 → 查看本库素材 → 只看核对后缺失」** 中核对后批量回收失效记录。

---

## 6. 按喜好定制外观与界面语言

- **切换语言**：进入 **「设置 → 界面语言 / Language」**，支持「跟随系统 / 简体中文 / English」免重启热切换。
- **一库一风 & 壁纸**：进入 **「设置 → 本库外观」** 为当前仓库单独挑选内置预设或 `.hytheme` 主题包，也可以直接**右键库里任意一张图片 →「设为本库壁纸」**，再按需调节毛玻璃与贴纸。
