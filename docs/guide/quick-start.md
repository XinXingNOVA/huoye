# 5 分钟上手活页

这份指南带你用几份随手找来的图片、PDF 或文字，快速走完一次「建库 → 收录 → 整理 → 多形态浏览 → 安全编辑与撤销」的完整体验。

> 首次体验建议新建一个测试仓库，放几份不重要的样本文件试试手，熟悉仓库与文件空间的关系后再导入主力资料。

---

## 1. 创建你的第一个仓库

打开 **活页（Huoye）**，在开始页点击 **「新建仓库」**，填好仓库名称和保存位置。

在起始方案里，首版内置了三种开箱选择：
- **视觉素材库（推荐初次体验）**：预装文件夹、标签基础与分组、评分、画幅尺寸、色彩与色板、笔记、来源，打开就是单区瀑布流 + 左上导航 + 左下智能筛选 + 右侧详情。
- **通用资料与表格库**：预装标签、笔记、来源、摘录批注、自定义字段、表格视图与受控文件编辑，适合整理 PDF、文章、结构化清单。
- **空白底座**：只启用宿主基础能力，适合想自己从零挑选插件的用户。

文件空间保持默认的「随仓库新建独享空间」即可，点击创建就会进入工作台。

---

## 2. 拖入素材，等待后台加工

把几张图片、PDF 或纯文本直接拖进主窗口，或点击最左侧快捷栏的 **「导入文件」** / **「新建文字」**：

1. 文件会先进入**文件空间**获得独立于路径和文件名的稳定身份，再按规则收录进当前仓库成为一条素材。
2. 后台加工会自动为你生成缩略图；如果启用了「画幅与尺寸」和「色彩与色板」，也会在后台算好宽高比例、色板与标准色系。
3. 如果你正在浏览一个**带筛选条件的视图**并直接拖入外部文件，未满足条件的条目会先弹出预检提示，由你决定是跳过还是仍收录进库，不会悄悄塞进视图造成混乱。

---

## 3. 整理、组合筛选与保存视图

选中任意素材（支持多选批量操作）：
- **右侧详情栏**：打标签、评 1～5 星、写笔记、记来源；如果启用了自定义字段，还可以给素材挂上自定义模板并填字段。
- **左侧智能筛选**：点击标签、星级、画幅或色系即可实时叠加筛选。侧栏计数会跟随当前页面的查询范围联动，但不会因为选中某个标签就把同组的其他标签藏起来。
- **保存为视图**：把常用的一组筛选与排序（例如“4 星以上横图”或“某个项目的待阅 PDF”）保存为视图。同一份素材可以同时出现在多个保存视图中，完全不复制文件。
- **双击 / 空格**：空格快速预览，双击打开阅读或查看；安装了多种打开器时可以在右键菜单选择「打开方式」并记住按扩展名的默认偏好。

---

## 4. 切换形态与自由分屏

活页的同一份查询结果，可以随时切换成不同的呈现方式：

- **切换浏览布局**：在集合页顶部打开 **「显示」** 菜单，即可在内置瀑布流与已启用的布局插件（如表格、画廊、时间线、看板）之间自由切换；布局选项可以随视图一起保存。
- **自由分屏与独立小窗**：
  - 把任意标签页拖到中央区域的上下左右边缘，即可递归分屏，一边翻列表一边对照阅读或编辑；
  - 右键标签页或把标签直接拖出主窗口，还能拆成独立的**内容小窗**（仍然共享同一个仓库会话与草稿）；
  - 按 `Cmd + P`（Windows 为 `Ctrl + P`）随时呼出命令面板。
- **保存工作台预设**：把顺手的分屏与侧栏安排保存成命名预设，按任务一键切换，工作台布局与素材业务数据彼此独立。

---

## 5. 撤销、受控编辑与原件取回

活页把“修改元数据”和“动磁盘原件”分得很清楚，用起来更安心：

- **会话撤销 / 重做**：常规的打标、写笔记、评分、改字段等仓库操作，都支持本次会话内的线性撤销与重做（默认保留最近 1000 笔），也可以打开操作历史面板查看明细。
- **安全编辑外部原件**：想用 Photoshop、Typora 或其他本机程序修改库里的原件，请不要去磁盘里直接改文件空间里的文件，而是右键选择 **「编辑文件」**。活页会为你准备一份**受控工作副本**；你在外部保存后，回到活页点 **「完成编辑」**，确认后就会作为新版本发布到文件空间并由本库接纳。
- **回收与取回原件**：
  - 在仓库里把素材「移入回收站」只影响本库记录，**不等于删除原件**；
  - 想查看文件版本、多库关联情况、或彻底清理原件，统一在 **「文件空间」** 页面操作，每一步都有清晰的影响预览；
  - 随时可以通过右键或导出把原件完整取回到本机任意目录。
