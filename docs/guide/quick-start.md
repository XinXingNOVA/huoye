# 5 分钟上手活页

这份指南带你用几份随手找来的图片、PDF 或文档，快速走完一次「建库（原地目录或托管空间） → 收录 → 整理 → 多形态分屏与置顶小窗 → 主题与安全编辑」的完整体验。

> 首次体验建议新建一个测试仓库，放几份不重要的样本文件试试手，熟悉仓库与文件空间的关系后再接入主力资料。

---

## 1. 创建你的第一个仓库（两种起步方式）

打开 **活页（Huoye）**，在开始页根据你的资料现状二选一：

- **方式 A：从本地文件夹开始…（零复制直连已有目录）**
  - 如果你的照片、电子书、文档或素材已经整理在电脑的某个文件夹里，点击 **「从本地文件夹开始…」** 选择该目录，再把活页仓库保存在来源目录以外的位置；
  - 首次打开仓库时，可按文件类型或后缀预览数量并一键收录。**原件留在原处，不复制、也不往你的文件夹里写入任何隐藏文件。**
- **方式 B：新建仓库（托管空间，带完整历史版本）**
  - 点击 **「新建仓库」**，填好名称与保存位置；文件空间保持默认的「随仓库新建独享空间」即可。需要保留修订历史的文件也可以随时从原地目录转为托管副本。

> 已建过仓库时点 **「打开已有仓库」** 即可；如果不小心选了普通非空文件夹，开始页也会直接引导你转为原地关联建库。

开箱内置三种起步方案（也可以导入官方扩展仓 [huoye-extensions](https://github.com/XinXingNOVA/huoye-extensions) 的 8 套场景套件）：
- **视觉素材库**：文件夹、标签、评分、画幅尺寸、色板、笔记、来源，打开即瀑布流 + 智能筛选。
- **通用资料与表格库**：标签、笔记、来源、摘录批注、自定义字段、表格视图与受控文件编辑。
- **空白底座**：只启用宿主基础能力，从零按需装配。

---

## 2. 拖入素材或按类型收录

- **导入托管文件**：把图片、PDF、音视频或文本直接拖进主窗口，或点左侧快捷栏的 **「导入文件」** / **「新建文字」**。
- **关联更多本地文件夹**：在仓库内随时可通过 **「文件空间」** 关联额外的原地目录，按后缀预览并批量收录。
- **后台加工**：活页会在后台生成缩略图、色板与画幅等可重建派生结果，原始记录（`library.db`）与派生缓存（`derived.db`）严格分离。
- **条件视图拖入预检**：如果在带筛选条件的视图里拖入文件，未满足条件的条目会先弹出预检提示，由你决定跳过或仍收录进库。

---

## 3. 整理、组合筛选与保存视图

选中任意素材（支持多选批量操作）：
- **右侧详情栏**：打标签、评 1～5 星、写笔记、记来源；启用自定义字段后可挂载模板并填写结构化字段。
- **左侧智能筛选**：点击标签、星级、画幅或色系即可实时叠加筛选。
- **保存为视图**：把常用筛选与布局（如「待校样」「4 星以上横图」）保存为视图。同一份素材可出现在多个视图里，不复制文件。
- **空格 / 双击**：空格快速预览，双击打开阅读或查看；装了多种打开器时可右键「打开方式」并记住按扩展名的默认偏好。

---

## 4. 切换形态、自由分屏与置顶小窗

同一批资料，可以随时换一种工作方式：

- **切换浏览布局**：在集合页顶部打开 **「显示」** 菜单，在瀑布流、表格、画廊、看板、书架、唱片墙等已启用视图之间切换。
- **递归分屏与布局预设**：把标签页拖到中央区域四边即可分屏对照；把顺手的排布存成工作台预设，按任务一键切换。
- **撕出置顶小窗**：右键标签页或拖出主窗口，即可变成独立的**内容小窗**（参考板、PDF、收纳盒等还可切为无框置顶小窗，贴在其他软件旁边干活）。
- **命令面板**：按 `Cmd + P`（Windows 为 `Ctrl + P`）随时呼出。

---

## 5. 撤销、安全编辑与原件管理

- **会话撤销 / 重做**：打标、写笔记、评分、改字段等常规操作均支持线性撤销与重做（默认保留最近 1000 笔）。
- **原地收录文件的外部编辑**：右键 **「在外部应用中打开原件」**；外部保存后回到活页双击或点 **「核对并预览新版…」** 确认接纳，原有标签和笔记保留。若需要保留旧版本原件，请先 **「转为托管副本…」** 再编辑。
- **托管文件的受控编辑**：右键 **「编辑文件」** 会准备一份工作副本；外部保存后回到活页 **「完成编辑」**，即发布为空间新版本并由本库接纳。
- **回收与改名移位接续**：
  - 仓库里「移入回收站」只影响本库记录，**绝不删除磁盘原件**；
  - 原地目录改名后点「刷新目录」、跨子目录移动后点「核对整个空间」，即可接回原素材与所有笔记。

---

## 6. 切换语言与外观

- **双语热切换**：进入 **「设置 → 界面语言 / Language」**，支持「跟随系统 / 简体中文 / English」免重启切换。
- **一库一风**：进入 **「设置 → 本库外观」** 为当前仓库单独选用主题、强调色、密度、圆角或壁纸。
